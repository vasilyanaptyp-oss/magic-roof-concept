# MAGIC ROOF e.U. website concept

A responsive, static, interactive homepage concept for MAGIC ROOF e.U. in Linz.

## Run locally

Serve this folder with any static HTTP server and open `index.html` through localhost.

## Included

- Responsive desktop, tablet and mobile layouts
- Accessible navigation and legal dialogs
- Reduced-motion support
- Local-business structured data
- Click-to-call, email and map actions
- Contact form that prepares a local email without storing or transmitting data
- Self-hosted font and GSAP runtime
